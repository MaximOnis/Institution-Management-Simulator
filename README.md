## Institution Management Simulator

A desktop simulator for accounting at educational institutions and other organizations, developed in Python. The program simulates the processes of billing, tracking accounts receivable, and collecting payments for various types of institutions.

Initial data is generated when the program starts and is used to demonstrate how to work with accounting objects and operations.

## Features

- View a list of institutions in various categories.
- Add, edit, and delete institutions.
- Filtering institutions by type.
- Tracking service costs and outstanding balances.
- Support for various payment types: daily, weekly, monthly, and annual.
- Simulating payment calculations for missed days or weeks.
- Simulating debt repayment.

## Technologies

- Python — primary programming language.
- Tkinter — graphical user interface development.
- Pandas — data processing and visualization.

## Project Structure

- main.py — program launch and initial data creation.
- MyGUI.py — graphical user interface.
- MyLists.py — manages lists of institutions.
- Institution.py — institution classes and debt calculation logic.

## Purpose

This project was created for educational purposes and demonstrates the application of object-oriented programming, class inheritance, working with data structures, and developing graphical user interfaces in Python.
