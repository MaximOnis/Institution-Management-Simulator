## Institution Management Simulator

Десктопний симулятор обліку навчальних закладів та інших організацій, розроблений на Python. Програма моделює процеси нарахування оплати, обліку заборгованості та її погашення для різних типів установ.

Початкові дані формуються під час запуску програми та використовуються для демонстрації роботи з об'єктами й операціями обліку.

## Можливості

- Перегляд списку установ різних категорій.
- Додавання, редагування та видалення установ.
- Фільтрація установ за типами.
- Облік вартості послуг і заборгованості.
- Підтримка різних типів оплати: денна, тижнева, місячна та річна.
- Моделювання нарахування оплати за пропущені дні або тижні.
- Моделювання погашення заборгованості.

## Технології

- Python — основна мова програмування.
- Tkinter — створення графічного інтерфейсу.
- Pandas — обробка та представлення даних.

## Структура проєкту

- main.py — запуск програми та створення початкових даних.
- MyGUI.py — графічний інтерфейс.
- MyLists.py — управління списками установ.
- Institution.py — класи установ і логіка розрахунку заборгованості.

## Призначення

Проєкт створений з навчальною метою та демонструє застосування об'єктно-орієнтованого програмування, наслідування класів, роботу зі структурами даних і розробку графічних інтерфейсів на Python.
